# CHARTER Website

First iteration of the CHARTER marketing and commerce scaffold for `charterfarms.co.uk`.

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/`
- `/products`
- `/living-certificate`
- `/products/bone-broth`
- `/products/bullshot`
- `/products/biltong`
- `/blog`
- `/blog/regenerative-farming-practices`

## Deploy

The repo is intended to deploy through Vercel Git integration from the `main` branch.
